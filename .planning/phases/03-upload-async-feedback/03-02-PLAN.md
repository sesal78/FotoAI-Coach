  **Step 1: Add a useSubmissionFeedback hook**

  In `nextjs_space/hooks/use-dashboard-data.ts`, add a new hook:

  ```typescript
  export function useSubmissionFeedback(submissionId: string | null) {
    return useQuery({
      queryKey: ['submission-feedback', submissionId],
      queryFn: async () => {
        const res = await fetch(`/api/submissions/${submissionId}`, { cache: 'no-store' });
        if (!res.ok) throw new Error('Failed to fetch feedback status');
        const data = await res.json();
        return data.submission as { id: string; feedbackStatus: string; feedback: string | null };
      },
      enabled: !!submissionId,
      refetchInterval: (query) => {
        // Poll every 2 seconds while feedback is pending, stop when ready
        const data = query.state.data;
        if (data?.feedbackStatus === 'ready') return false;
        return 2000;
      },
    });
  }
  ```

  **Step 2: Update dashboard submission flow**

  In `nextjs_space/app/dashboard/page.tsx`:

  a) Import `useSubmissionFeedback` from `@/hooks/use-dashboard-data`

  b) Add state to track the last submission ID:
     ```
     const [lastSubmissionId, setLastSubmissionId] = useState<string | null>(null);
     ```

  c) Add the feedback polling hook:
     ```
     const { data: feedbackData } = useSubmissionFeedback(lastSubmissionId);
     ```

  d) In `submitChallenge()`, after `response.ok`: capture the submission ID:
     ```
     setLastSubmissionId(data.submission.id);
     ```
     Remove the line `toast.success(data.submission.feedback || 'Great work!');` (feedback is no longer in the submission response). Keep the `toast.success('Challenge submitted! 🎉')`.

  e) Add a `useEffect` that watches `feedbackData` and shows a toast when feedback becomes ready:
     ```
     useEffect(() => {
       if (feedbackData?.feedbackStatus === 'ready' && feedbackData.feedback) {
         toast.success(feedbackData.feedback);
         setLastSubmissionId(null); // Stop polling
       }
     }, [feedbackData]);
     ```
     Import `useEffect` from React (it was removed in plan 02-02, add it back).

  **What NOT to do:**
  - Do NOT show a persistent loading indicator in the UI — just show the success toast for submission, then a second toast when feedback arrives
  - Do NOT change the React Query invalidation pattern — invalidateDashboard() still runs after submit
  - Do NOT modify the submission form behavior or the skipChallenge flow (skip doesn't generate feedback)
