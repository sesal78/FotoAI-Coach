# Foto Next.js Application

This is the main Next.js application for the Foto AI Photography Coach platform.

## Development

```bash
# Install dependencies
yarn install

# Generate Prisma client
yarn prisma generate

# Run development server
yarn dev
```

## Build

```bash
yarn build
yarn start
```
